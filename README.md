# SOUND mobil

SOUND'un mobil sürümlerinin kaynak kodu. Masaüstü uygulaması ve ortak kod aynı deponun `main` dalındadır.

- [`androidVersion/`](androidVersion/README.md): Android uygulaması ve derleme, yayınlama adımları
- `update/android.json`: uygulamanın kendini güncellerken baktığı sürüm bilgisi

**[En son APK'yı indir](https://github.com/Sefikak/SOUND/raw/android-0.1.3/SOUND-android-0.1.3.apk)**. Kurduktan sonra yeni sürümler uygulamanın içinden gelir.
